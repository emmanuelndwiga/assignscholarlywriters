Frontend Design

The public interface is being developed around a modern government digital-service aesthetic with:

Purple as the primary brand identity
White and soft lavender backgrounds
Deep purple typography
Red reserved for Quick Exit and urgent actions
Responsive layouts for desktop, tablet, and mobile
Accessible typography, spacing, focus states, and interaction targets
Structured cards, reporting steps, support sections, and calls to action
Current Development Status

The core Django system is running successfully, and the current work is focused on refining the public landing page and frontend design system while maintaining compatibility with the existing reporting, tracking, accounts, cases, and notification functionality.
